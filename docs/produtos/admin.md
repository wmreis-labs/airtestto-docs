# Admin

Console administrativa que consome as APIs do airtestto. O repositório da interface foi iniciado com Create React App.

## Desenvolvimento

```bash
npm install
npm start
```

O modo de desenvolvimento recarrega ao salvar. `npm test` abre o runner. `npm run build` gera a pasta `build`.

Autenticação e tenant seguem o [domínio Auth](../dominios/auth.md). Variáveis de ambiente ficam no repositório da interface e não são republicadas aqui.
