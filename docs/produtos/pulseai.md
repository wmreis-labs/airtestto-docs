# PulseAI

Aplicativo móvel da plataforma PulseAI. React Native, Expo e TypeScript, no mesmo desenho modular do [Hostto App](hostto-app.md).

Módulos de domínio, camada HTTP tipada, React Query e armazenamento seguro da autenticação. A tela passa pelo hook; o hook chama a API; a API chama o backend.

```bash
npm install
npx expo start
npm run android
npm run ios
```
